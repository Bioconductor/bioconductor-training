EuroBioC2025 Carpentry Workshop: Bulk RNA-seq

Description

Analysis and interpretation of bulk RNA sequencing data with Bioconductor: This course shows how to use Bioconductor packages to analyse bulk RNA-seq data including how to import and annotate quantified data into R, exploratory analysis and quality control, differential expression analysis and gene set enrichment analysis.

Pre-requisites: Familiarity with R and Bioconductor.

Instructors: Estefania Mancini, Vasileios Panagiotis Lenis, Jacques Serizay
